# one-round genome scan with specified cofactor(s)

one-round genome scan with specified cofactor(s)

## Usage

``` r
scanQTL(
  modDat,
  map,
  markers,
  parents,
  QTLwindow = 10,
  cof = NULL,
  Usc = NULL,
  trait = NULL,
  maxIter = 100,
  se = FALSE,
  parallel = FALSE,
  verbose = FALSE
)
```
