# statgenMPP: QTL Mapping for Multi Parent Populations

For Multi Parent Populations (MPP) Identity By Descend (IBD)
probabilities are computed using Hidden Markov Models. These
probabilities are then used in a mixed model approach for QTL Mapping as
described in Li et al.
([doi:10.1007/s00122-021-03919-7](https://doi.org/10.1007/s00122-021-03919-7)
).
